# Jaipur, a planned city: DRAFT (waiting for the speaker recording)

This draft is timed to the script at an estimated speaking pace, with a "YOUR VIDEO" placeholder where the speaker appears (the opening line and the closing CTA).

**To finish it:**
1. Record the script.
2. Transcribe it to `project/words.json` (Parakeet word timings).
3. Save the 30 fps, −16 LUFS recording as `project/proj/assets/avatar.mp4`.
4. Run `python3 build.py`. Every caption and animation re-times automatically to the spoken words.
